# Security Policy

## Supported Versions
This is an early-stage open-source project. Security fixes are applied to the latest minor version.

## Reporting a Vulnerability
Please **do not** open a public issue for security reports.

Instead, send a report via:
- GitHub Security Advisories (preferred), or
- Email to the repository owner.

Include:
- Description of the vulnerability and impact
- Steps to reproduce (minimal and safe)
- Affected versions
- Any suggested mitigation

We aim to acknowledge reports quickly and provide a fix or mitigation guidance as soon as possible.

## Integridade e disponibilidade

Um arquivo inexistente não é histórico válido. Não acrescente registros a cadeias adulteradas. Em produção, utilize um único escritor por arquivo e arquive checkpoints do hash mais recente em sistema independente: sem âncora externa, a exclusão do final do histórico não é detectável somente pela cadeia.
