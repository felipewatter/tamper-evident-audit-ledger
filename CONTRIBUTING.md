# Contributing

Thanks for considering contributing.

## Development setup

```bash
npm ci
npm test
npm run lint
npm run build
```

## Guidelines
- Keep changes small and focused.
- Add/adjust tests for behavior changes.
- Document new flags/options in README.
- Avoid adding heavy dependencies; prefer Node built-ins.

## Commit style
Use clear, imperative commit messages (e.g., "Add CLI verify command").

## Pull requests
- Explain the "why" and "what".
- Link relevant issues.
- Ensure CI passes.
